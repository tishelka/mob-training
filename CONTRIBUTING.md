# Как сдавать задания

Здесь два мобильных разработчика будут менять одни и те же файлы. Поэтому **лучше каждому сделать fork** этого репозитория и проходить курс самостоятельно.

1. На GitHub нажмите Fork, клонируйте адрес **своего** репозитория.
2. Читайте уроки и выполняйте задания по порядку. Каждый следующий этап может опираться на предыдущий код.
3. На контрольный этап создайте ветку, например `practice/ts-basics`.
4. Сделайте commit, push и PR **в master своего fork**. Ссылку отправьте руководителю. Если он попросит, откройте PR и в исходный учебный репозиторий.
5. Напишите, что получилось и чем проверяли.

Для языка: в папке `typescript/` — `npm run check` и `npm test`. Для приложения: в корне — `npm run typecheck` и `npm test`.

Не добавляйте в Git `node_modules`, секреты или личные данные. Не подменяйте самостоятельную практику копированием готовых решений.
