# Финал. Собери мини-приложение «Идеи для отдыха»

Теперь попробуй построить небольшое приложение самостоятельно — **не копируя готовые экраны «ЧтоДальше»**.

## Что должно работать

- [ ] Три экрана: список, детали и избранное.
- [ ] Переходы через Expo Router.
- [ ] Переиспользуемая карточка с типизированными props.
- [ ] Фильтры по категории и бюджету.
- [ ] Понятные состояния пустого списка и ошибки ввода.
- [ ] Добавление и удаление избранного без дублей.
- [ ] Чистые функции и хотя бы несколько тестов Vitest.
- [ ] Команды `npm run typecheck` и `npm test` проходят.
- [ ] Приложение проверено в браузере или эмуляторе.

## Дополнительный уровень

Подключи собственный FastAPI из [backend-training](https://github.com/tishelka/backend-training), обработай loading/error, добавь кнопку повтора. Учти несовпадения формата данных и проверяй JSON на входе.

## Как покажешь результат

Попроси другого студента без подсказок найти занятие, открыть карточку, применить фильтр и добавить идею в избранное. После этого объясни руководителю, где лежат экран, компонент, тип Activity и функция фильтрации.

Когда закончишь, можно переходить к [настоящему MVP «ЧтоДальше»](https://github.com/tishelka/chtodalshe).
