# RN-05. Форма фильтров

**Сначала:** [формы и фильтры](../docs/15-forms-and-filters.md).

Создайте экран с `TextInput` для бюджета и выбором категории (`walks`, `games`, `creative`, «Любая»). Параметры храните в состоянии, для фильтрации используйте функцию в `src/lib/`.

Не пытайтесь считать ввод числом до преобразования: `TextInput` отдаёт строку. Обработайте пустую строку, отрицательное число и буквы.

**Проверка:** нулевой бюджет показывает только бесплатные идеи, категория правильно фильтруется, неправильный ввод вызывает понятную ошибку вместо падения.

Добавьте пару тестов Vitest для чистой функции фильтрации.
