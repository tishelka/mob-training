# RN-06. Подключаем FastAPI

**Сначала:** [API и ошибки](../docs/16-api-and-errors.md).

Теперь попробуйте заменить локальный список запросом к серверу. Для упражнения можно использовать **свой backend-training** с работающим `GET /activities`.

1. Укажите `EXPO_PUBLIC_API_URL` в локальном `.env` (не коммитьте его).
2. В `src/api/activities.ts` есть пример `fetch`. Реализуйте проверку полученного JSON и преобразование в тип Activity (названия полей и ID сервера могут отличаться).
3. Отображайте **loading**, **error** с кнопкой повтора и **ready**.
4. Выключите backend и убедитесь, что показывается ошибка, а не пустой список.

На физическом телефоне API URL должен указывать на IP вашего компьютера в локальной сети, а не `localhost`.

**Готово, если:** успешная загрузка, ошибка соединения и повторная попытка работают предсказуемо.
