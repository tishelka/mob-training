# RN-07. Проверяем логику

**Сначала:** [тестирование](../docs/18-mobile-testing.md).

Напишите в Vitest тесты на фильтры: пустой список, 0 рублей, точно равную бюджету цену, комбинацию бюджета и категории.

Запустите:

```bash
npm run typecheck
npm test
```

Дополнительно вручную пройдите сценарий: главная → детали → избранное → фильтры → возврат назад. Запишите результат и баги в PR.

**Цель:** не просто увидеть зелёную галочку, а понять, какие ошибки ваш тест реально поймает.
