# RN-04. Добавляем избранное

**Сначала:** [useState](../docs/14-state-and-hooks.md), [Context](../docs/17-context-architecture.md).

Сделайте кнопку «В избранное» на карточке или экране детали. При нажатии ID должен добавляться в массив состояния, при повторном — удаляться.

Покажите избранные активности на отдельной вкладке. Сначала держите состояние в общем компоненте/контексте **в памяти**, без сервера.

**Проверьте:** повторное добавление не создаёт дубликаты; после удаления карточка исчезает из избранного; обе вкладки видят одно состояние.

**Важно:** после перезапуска приложения данные потеряются — это **ожидаемо на этом этапе**. Сохранение через API изучим позже.
