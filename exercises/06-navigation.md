# RN-03. Страницы и навигация

**Сначала:** [Expo Router](../docs/13-expo-router.md).

1. Добавьте экран `app/about.tsx` с описанием приложения.
2. Добавьте ссылку с главной страницы на него.
3. Добавьте группу `app/(tabs)/` с вкладками «Главная» и «Избранное». Для начала экран избранного может быть пустым.
4. Сохраните возможность открывать `activity/[id]` и возвращаться назад.

**Подсказка:** в `app/(tabs)/_layout.tsx` используется компонент `Tabs`. Перенос главной страницы из `app/index.tsx` в `app/(tabs)/index.tsx` требует продумать стартовый маршрут и обновить корневой layout.

**Проверьте:** назад работает, вкладки переключаются, детальная страница показывает правильный ID, неизвестный ID не вызывает падение.
