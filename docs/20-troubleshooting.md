# 20. Когда ничего не работает

**`node` или `npm` не находится:** проверьте установку Node.js 22.13+ и перезапустите терминал.

**`Cannot find module`:** сначала выполните `npm install` в **нужной папке**. У `typescript/` свой `package.json`, у приложения — свой.

**`Cannot use JSX unless ...`:** файл с JSX должен иметь расширение `.tsx`, а не `.ts`.

**`Type 'string' is not assignable to type 'number'`:** проверьте ввод из `TextInput`. Строку придётся преобразовать и проверить.

**`Expo Go не открывает проект:** убедитесь, что версии Expo SDK и установленного Expo Go совместимы. Возможен запуск через web или эмулятор.

**`Port 8081 is in use`:** Metro уже запущен в другом терминале. Остановите лишний процесс или согласуйте другой порт.

**`Network request failed` на телефоне:** проверьте, что backend запущен, телефон и ноутбук в одной сети, а API URL не содержит `localhost` вместо LAN IP компьютера.

**Нажатие не открывает экран:** проверьте путь в `Link` и соответствующий файл в `app/`.

**`Cannot find route`:** проверьте название маршрута и перезапустите Expo с `npx expo start --clear`.

При обращении за помощью приложите ошибку, команду и файл, в котором проблема. Не делитесь токенами и личными данными.
