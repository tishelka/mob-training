# 09. Expo: как запустить приложение

**React Native** позволяет писать мобильные экраны на React и TypeScript. **Expo** предоставляет инструменты сборки, разработки и часть возможностей устройства.

Новый проект можно создать так:

```bash
npx create-expo-app@latest my-first-app
cd my-first-app
npx expo start
```

Но для наших заданий уже есть маленькая заготовка в корне репозитория. Выполните там:

```bash
npm install
npm run start
```

`Metro` собирает код, Expo выводит QR-код и команды запуска. Для браузера: `npm run web`. Для Android-эмулятора: Android Studio. Для iOS Simulator: macOS с Xcode. Для физического телефона нужна совместимая версия Expo Go и доступ к Metro.

На телефоне `localhost` означает **сам телефон**, а не ваш ноутбук. Это станет важно при подключении FastAPI.

В этом учебном репозитории используется Expo SDK 57, React Native и Expo Router. В новом проекте, созданном через `create-expo-app`, версии могут отличаться. Не переносите зависимости между разными SDK вслепую.
