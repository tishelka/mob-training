# 01. Знакомимся с TypeScript

TypeScript — это JavaScript с проверкой типов. Он замечает многие ошибки **до запуска**. Пример: `let time: number = 60`; попытка `time = "час"` вызовет ошибку проверки.

**JavaScript выполняется**, а TypeScript обычно сначала проверяется и преобразуется в JavaScript. В React Native TypeScript тоже помогает редактору подсказывать поля компонентов и данных.

В этом репозитории есть отдельная папка `typescript/`. В ней можно тренироваться без телефона:

```bash
cd typescript
npm install
npm run demo
npm run check
npm test
```

`npm run demo` выполняет `src/demo.ts` с помощью `tsx`. `npm run check` запускает `tsc --noEmit`: проверяет типы, но не создаёт новых файлов.

**Что попробовать:** поменяйте тип переменной в `demo.ts`, затем сознательно присвойте ей значение другого типа и запустите `npm run check`. Посмотрите, как редактор объясняет ошибку. Исправьте её.
