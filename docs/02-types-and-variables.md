# 02. Переменные и типы: не путаем цену с названием

`const` — переменную нельзя переназначить, `let` — можно. Предпочитайте `const`, когда не собираетесь менять значение.

```typescript
const title: string = "Прогулка";
let minutes: number = 60;
const isFree: boolean = true;

minutes += 15; // теперь 75
```

Тип часто определяется автоматически: `const cost = 100` уже имеет числовой тип. Нет нужды писать `: number` в каждой строке, но на границах функций и в моделях явные типы помогают.

`undefined` — значение отсутствует; `null` — явно пустое значение. Они не равны нулю или пустой строке. Поиграйте с `??`: `const budget = inputBudget ?? 0`.

**Не злоупотребляйте `any`**: это фактически выключает проверку. Если не знаете тип внешнего JSON, выбирайте `unknown` и проверяйте данные перед использованием.

**Упражнение:** заведите переменные для имени занятия, бюджета и количества участников; выведите строку через шаблонные литералы ``...${value}...``.
