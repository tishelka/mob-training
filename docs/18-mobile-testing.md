# 18. Что тестировать у мобильного приложения

Быстрая проверка:

```bash
npm run typecheck
npm test
```

В `tests/filterActivities.test.ts` есть Vitest-тест **чистой функции** фильтрации. Такие тесты быстрые, потому что не нужно запускать эмулятор.

Но интерфейс тоже проверяйте вручную: открывается ли карточка, работает ли кнопка «Назад», что происходит при пустом списке и некорректном вводе, не выходит ли текст за экран.

Для более сложного приложения пригодятся E2E-тесты, например Playwright для веб-версии. Но **с первого дня их настраивать не нужно**: сначала типы, компоненты, навигация и чистые функции.

**Проверьте:** бюджет 0, ровно 100, пустые данные, неизвестный ID, отсутствие подключения к API.
