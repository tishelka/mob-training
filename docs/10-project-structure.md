# 10. Что где лежит: карта проекта

Когда новичок открывает Expo-проект, кажется, что файлов слишком много. На самом деле каждый отвечает за свою часть:

| Путь | Для чего |
|---|---|
| `package.json` | Зависимости, скрипты запуска |
| `app.json` | Название, slug и параметры Expo |
| `tsconfig.json` | Проверка TypeScript |
| `app/` | **Маршруты экранов** Expo Router |
| `app/_layout.tsx` | Общая навигационная оболочка |
| `src/components/` | Переиспользуемые компоненты |
| `src/data/` | Источники данных (пока локальные) |
| `src/types/` | Типы активностей и фильтров |
| `src/api/` | HTTP-запросы к backend |
| `src/theme/` | Палитра и общие стили |

Начните с `app/index.tsx`. Он получает список из `src/data/activities.ts`, а карточку берёт из `src/components/ActivityCard.tsx`.

**Полезная привычка:** экран — это место сборки элементов, а не место, куда нужно записать всю логику приложения. Позже вынесем фильтры в чистые функции.
