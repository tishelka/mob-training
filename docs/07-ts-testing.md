# 07. Typecheck и тесты — две разные проверки

`npm run check` вызывает TypeScript-компилятор и ищет ошибки **типов**. Но успешная проверка не гарантирует, что ваша функция правильно считает бюджет.

Для поведения используем **Vitest**:

```typescript
import { expect, it } from "vitest";

it("проверяет стоимость", () => {
  expect(100 <= 200).toBe(true);
});
```

В `typescript/tests/utils.test.ts` есть тест функции `getAffordable`. Запустите `npm test`. Потом измените условие в `typescript/src/utils.ts`, чтобы тест упал, и верните правильное.

Что важно проверять: пустой список, нулевой бюджет, точное совпадение цены, слишком дорогое занятие. Это ещё не мобильное тестирование — только логика.
